# 星空創作祭 公式サイト

GitHub Pagesで公開する、ビルド不要の静的サイトです。既存の星空創作祭のキービジュアルを使用しています。

## ファイル

- `index.html`: 公式トップページ、開催案内、お知らせ
- `styles.css`: パソコン・タブレット・スマートフォン用のスタイル
- `site.js`: スマートフォンのメニューとナビゲーション
- `credits.html`: 星図データとアイコンのクレジット
- `assets/`: キービジュアル、アイコン、第三者ライセンス

開催日時・開催形式・参加方法は未確定のため、準備中と明記しています。確定情報が届いたら `index.html` の開催案内とお知らせを更新してください。参加受付、問い合わせ先、公式SNSは未指定のため設置していません。

## 公開

GitHubリポジトリの Settings > Pages で、Deploy from a branch / main / (root) を指定します。`.nojekyll` によりそのまま公開されます。サブディレクトリへの公開に対応した相対パスを使用しています。

## ローカル確認

`index.html` をブラウザーで開けます。HTTPで検証する場合は、任意の静的ファイルサーバーでこのフォルダーを配信してください。インストールやビルドは不要です。

## 素材

キービジュアルは提供された既存デザインを使用しています。このリポジトリは、ビジュアル全体について新たな再配布ライセンスを付与するものではありません。星図データとLucideのライセンスは `assets/` に収録しています。
